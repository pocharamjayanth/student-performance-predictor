# Student Performance Predictor

An end-to-end machine learning web application that predicts student academic performance based on demographic, social, and academic factors. The goal of this project is to help educators and institutions identify students who may need early academic intervention by modeling underlying trends in performance data.

---

## 📌 Project Overview

Predicting academic outcomes early in a term enables proactive intervention rather than reactive grading. This application provides a web interface where users can input student data—such as study hours, attendance, parental education level, and previous test scores—to receive an estimated performance score generated by a trained regression pipeline.

### Key Highlights
- **End-to-End Pipeline:** Data cleaning, exploratory analysis, preprocessing (encoding & scaling), model training, and deployment.
- **Model Evaluation:** Evaluated multiple regression algorithms (Linear Regression, Decision Trees, Random Forest, Gradient Boosting) to select the optimal model based on R² score and Mean Absolute Error (MAE).
- **Web Interface:** Interactive frontend built with Flask/Streamlit for real-time model inference.
- **Production-Ready Structure:** Modular codebase structured for scalability, maintainability, and clean separation of concerns.

## ⚡ Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites
- Python 3.8+ installed on your system.
- Git configured.

### 1. Clone the Repository
```bash
git clone [https://github.com/pocharamjayanth/student-performance-predictor.git](https://github.com/pocharamjayanth/student-performance-predictor.git)
cd student-performance-predictor
2. Set Up a Virtual Environment
Bash
# On Windows
python -m venv venv
venv\Scripts\activate

# On macOS/Linux
python3 -m venv venv
source venv/bin/activate
3. Install Dependencies
Bash
pip install -r requirements.txt
4. Run the Application
Bash
python app.py
Open your browser and navigate to http://127.0.0.1:5000/ (or the port specified in your terminal) to access the predictor interface.

📊 Workflow & Methodology
Data Ingestion: Loads raw student metrics from CSV files and splits them into training and evaluation sets.

Data Transformation:

Numerical feature scaling using StandardScaler.

Categorical feature encoding via OneHotEncoder.

Pipeline serialized into a reusable preprocessor artifact.

Model Training & Selection:

Evaluated multiple models using Cross-Validation.

Fine-tuned hyperparameters to balance variance and bias.

Exported the best-performing model to the artifacts/ folder.

Inference Pipeline: Receives payload from web input forms, passes data through the preprocessor, and outputs predictions instantly.
